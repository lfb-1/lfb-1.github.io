# Fengbei Liu — academic website

Public site: <https://lfb-1.github.io/>

This is a Hugo site based on [Pascal Michaillat's hugo-website](https://github.com/pmichaillat/hugo-website) and its vendored PaperMod theme. It uses the template's minimal profile layout, with curated Recent News below the introduction. Publications, News, Experience, and Academic Service are separate pages. The homepage has no publication list; its Publications button opens the complete CV-based inventory. The CV is available through the profile's CV icon.

## Edit and preview

Use **Hugo Extended 0.169.0**, the version pinned in `.github/workflows/hugo.yml`. No Node.js packages or theme downloads are required.

```bash
hugo server --disableFastRender
# Open http://localhost:1313/

# Production validation
hugo --minify --panicOnWarning
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/build_publications.py --check
cmp cv/fbl_cv.pdf static/fbl_cv.pdf
```

- `config.yml`: introduction, contact links, buttons, navigation, and `params.news`.
- `content/`: pages for Publications, News, Experience, and Service.
- `data/publications.json`: complete CV-based inventory, including undated publications and preprints; generated by `scripts/build_publications.py`.
- `layouts/partials/index_profile.html`: profile layout and homepage news.
- `assets/css/extended/fengbei.css`: site-specific styling.
- `static/fbl_cv.pdf`: public CV, served at the existing `/fbl_cv.pdf` URL.
- `cv/fbl_cv.tex`: canonical CV source; see `cv/WORKFLOW.md`.
- `scripts/publish_cv.py`: copy a compiled CV and update the versioned links.
- `data/scholar.json`, `data/sync_report.md`: publication maintenance files; see `SYNC.md`.

Add news to `params.news` in `config.yml`, newest first. Use a confirmed announcement month when available, otherwise only the publication year in the CV. Do not infer acceptance or publication months. The homepage shows the first six entries; `/news/` shows all entries.

After changing the CV or saved Scholar inventory, run `python3 scripts/build_publications.py`. It preserves CV titles, author order, contribution marks, venue qualifiers, and preprint status, adding links from matched Scholar records. The build checks that the committed inventory is current. The JACC: Advances paper remains undated until its publication year is confirmed.

## Deployment

GitHub Pages uses **GitHub Actions**. Every push to `main` runs tests, builds with the pinned Hugo version, checks public files, uploads `public/`, and deploys that artifact. Pull requests run validation without deploying.

Only Hugo's output is published. CV sources, scripts, Scholar snapshots, and repository documentation are not copied into `public/`. The existing `/thesis/ElsnerTalk.pdf` URL is preserved through a static mount.

Build output (`public/`, `resources/`, `.hugo_build.lock`) is ignored. Do not edit generated HTML or recreate a root `index.html`.
