# CV Workflow

## Canonical files
- `fbl_cv.tex` — source
- `fbl_cv.pdf` — compiled output
- `UPDATE_LOG.md` — historical record

## Update procedure
1. verify changes from authoritative sources,
2. edit `fbl_cv.tex`,
3. compile locally when feasible,
4. record the update in `UPDATE_LOG.md`,
5. keep author labels generic (`Agent`, `Manual`, `Fengbei`).

## Logging template
```markdown
## YYYY-MM-DD: [Type of Update]

**Updated By:** Agent

### Changes Made
- ✅ [Change]
  - Source: [URL or source description]

### Files Updated
- ✅ fbl_cv.tex
- ✅ fbl_cv.pdf
```
